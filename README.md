# clock-timer

現在時刻とカウントダウンタイマーを全画面に大きく表示する、静的な1ページのWebアプリです。作業中に常時表示しておく用途を想定し、表示更新時のちらつきと再描画の回数を抑えています。

**Demo:** https://karaagec.github.io/clock-timer/

## 特長

- 上段に時計、下段にタイマーを `HH:MM` で同じ大きさに表示します。秒は数字の下の細いバーでのみ表します。
- 単一の `index.html` で、ビルドは不要です。外部依存は Google Fonts(Inter)だけです。
- 動作中のタイマーは終了時刻を基準に保持するため、再読み込みや再起動の後も正しく続きから進みます。

## ローカルで動かす

`index.html` をブラウザで直接開くだけで動作します。簡易サーバーを使う場合は次のとおりです。

```sh
python3 -m http.server 8000
# http://localhost:8000/ を開く
```

## 実装メモ

### ちらつき対策

- 各文字は幅固定の `<span>`(数字 `0.64em`、区切り `0.32em`)に入れ、変化した文字の `textContent` だけを書き換えます。桁の変化でレイアウトが揺れません。
- フォントの読み込み完了(最大1.5秒待機)まで数字を `visibility: hidden` にし、フォントの差し替えによるちらつきを防いでいます。

### 秒バー

- 毎秒の描画ループ(`setInterval` / `requestAnimationFrame`)は使っていません。
- 時計のバー: Web Animations API による 60秒・linear の `scaleX(0→1)` アニメーション1本です。分が変わったとき、および実時刻とのずれが600msを超えたときに `currentTime` を合わせ直します。
- タイマーのバー: 次に分の数字が減るまでの割合から `scaleX(f→0)` のアニメーションを作成し、ずれが1%を超えたら作り直します。停止中・一時停止中は静的な `transform` です。
- `prefers-reduced-motion: reduce` の環境では、どちらのバーも1秒刻みの `steps()` になります。

### 更新スケジュール

- `setTimeout` で、時計の分が切り替わる時刻と、タイマーの分の数字が変わる時刻のうち近い方に起きます。間隔は最大15秒で、そのたびにバーのずれを補正します。
- `visibilitychange` でタブが表示に戻ったときにも即時に更新します。

### タイマーの表示と状態

- 表示する値は `Math.ceil(残りms / 60000)` です(例: 残り24分1秒 → `00:25`)。
- 状態は `localStorage` のキー `clocktimer.v1` に保存します。

  ```json
  { "duration": 1500000, "mode": "idle", "remaining": 1500000, "endAt": 0, "mute": false }
  ```

  `mode` は `idle` / `running` / `paused` / `done` のいずれかです。`running` の間は `endAt`(終了時刻のエポックms)から残り時間を計算します。
- 設定できる範囲は1秒〜24時間です。

### 終了音

- Web Audio API で 880Hz のサイン波を3回鳴らします。自動再生の制限があるため、`AudioContext` は「開始」の操作時に作成します。

### 入力

時間の入力欄は `25`(分)、`1:30`(分:秒)、`90秒`、`5分30秒` の形式と全角数字に対応しています。

| キー | 動作 |
| --- | --- |
| `Space` | 開始 / 一時停止 / 再開 |
| `R` | リセット |
| `↑` / `↓` | ±1分 |
| `M` | 音のオン / オフ |
| `F` | 全画面(Fullscreen API 非対応の環境では非表示) |

## 外部への通信

- Google Fonts から Inter を読み込みます。読み込めない場合はシステムフォントで表示します。
- アクセス解析、Cookie、外部APIは使用していません。
